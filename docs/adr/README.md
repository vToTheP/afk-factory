# Architecture decision records

Short notes on decisions that someone would plausibly make differently, and why this project
made them the way it did. Not a changelog and not documentation of how things work — those
live in the README and in the code.

A record is added when a decision is load-bearing and non-obvious. When one is reversed, the
old record stays and is marked superseded; the history is the point.
